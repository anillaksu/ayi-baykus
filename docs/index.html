Ayı ile Baykuş

Claude Code durum çubuğunu, oturumun o anki hâline göre değişen piksel bir sahneye çeviren eklenti. Aşağıdaki görüntü gerçek Windows Terminal ekranından alındı.

Kurulum

claude plugin marketplace add anillaksu/ayi-baykus
claude plugin install ayi-baykus@ayi-baykus

Sonra Claude Code içinde /ayi-baykus:kur yazın. Önceki ayarınız yedeklenir, /ayi-baykus:kaldir geri getirir. Gerekenler: Bash 4.3 veya üstü, jq, 24-bit renkli terminal. Kaynak: github.com/anillaksu/ayi-baykus

Eski baykuş neden çamurlaştı

Terminal bir hücreye (2 piksel eni, 4 piksel boyu) en fazla 2 renk koyabiliyor. Eski çizimde hücrelere dış çizgi, gövde, göz ve arka plan birlikte düşüyordu. Terminal fazla renkleri attığı için yüz dağılıyordu. Yeni çizim bu ızgaraya göre yapıldı. Kırmızı çerçeveli hücreler sınırı aşanlar.

Birlikte ne yapıyorlar

  • Beklerken: 48 saniyelik küçük bir hikâye. Ayrı takılırlar, baykuş yanına uçar, selamlaşırlar, çak yaparlar, top atarlar, baykuş geri döner.
  • Düşünürken: ayı volta atar, baykuş ampulü getirir, ayının yüzü aydınlanır.
  • Bash çalışırken: ayı dizüstünde yazar, baykuş ekrana bakar ve arada tezahürat yapar.
  • Kod yazarken: ayı önündeki baykuşu kovalar.
  • Dosya okurken: yan yana okurlar, baykuş arada soru sorar, ayı ona döner.
  • Web'de: baykuş dışarı uçar, zarfla döner, ayının eline verir.
  • Yağmurda ve fırtınada: tek şemsiyenin altına girerler. Fırtınada ayı baykuşa sarılır.
  • Yazdıklarına göre: "aferin" yazınca aralarından kalp çıkar. "Bozuk" yazınca baykuş ayının omzunu sıvazlar.

Baykuş her zaman ayının sağında durur, üst üste binmezler. Sahne yalnız karakterin kendi hücrelerinde tek renge inip hafifçe kararır, çevresine dokunulmaz. Yürürken çift piksel adım attıkları için hücre ızgarasından kaymazlar.

Sınırlar

  • auto mode on satırına çizilemez. O satır Claude Code'un kendi alt bilgisi, durum çubuğu onun üstünde ayrı duruyor.
  • Kare hızı en çok saniyede 1. Claude Code durum çubuğunu daha sık yenilemiyor.
  • En ince çizim Windows Terminal'de. Başka terminallerde çeyrek bloklara düşer, karakterler daha kaba görünür.
  • Yazılar ve duygu sözcükleri şimdilik yalnız Türkçe.
  • Fare ve klavye olayı alınamıyor. Karakterler oturumda olan bitene ve yazdığın kelimelere tepki veriyor.
